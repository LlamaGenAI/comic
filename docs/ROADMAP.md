# 12-Month Roadmap

## Goal

Make `comic` the default open SDK for comic generation in JavaScript/TypeScript.

## Q2 2026

- Stabilize SDK API and error semantics
- Ship CI + issue templates + contribution workflow
- Add framework guides (Next.js, Express)

## Q3 2026

- Add streaming/pagination helpers where API supports them
- Add typed examples for Node, edge runtimes, and serverless
- Publish weekly release notes and changelogs

## Q4 2026

- Add telemetry hooks (opt-in) and structured logging adapters
- Add benchmark suite and reliability scorecard
- Launch community templates and starter apps

## Q1 2027

- Expand integrations and community plugins
- Harden docs with migration guides and compatibility matrix
- Run public roadmap voting and monthly office hours

## KPIs

- Monthly npm downloads
- GitHub stars, forks, contributors
- PR lead time and issue time-to-first-response
- Test coverage for public API paths
