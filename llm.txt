project: comic
repository: https://github.com/LlamaGenAI/comic
package: https://www.npmjs.com/package/comic
homepage: http://llamagen.ai/comic-api
language: TypeScript, JavaScript

summary:
comic is the official JavaScript/TypeScript SDK for LlamaGen Comic API.
It supports single generation, polling, batch generation, concurrency control,
and robust error handling for AI agent and creator workflows.

quickstart:
1) npm install comic
2) import { LlamaGenClient } from 'comic'
3) const llamagen = new LlamaGenClient({ apiKey: 'YOUR_API_KEY' })
4) await llamagen.comic.create({ prompt: 'american comic illustration, bold, thick outlines,vibrant, high-contrast colors, ...' })
5) await llamagen.comic.waitForCompletion(id)

- llamagen.comic.get
